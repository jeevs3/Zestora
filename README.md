# Zestora – Food Delivery Web Application

A full-stack food delivery application built using Java, JSP, Servlets, JDBC, and MySQL-compatible TiDB.

## Live Demo
https://zestora-muwq.onrender.com

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- TiDB
- HTML, CSS, JavaScript
- Apache Tomcat
- Docker
